# ctOS 2.0 有哪些功能

本文专门回答「这个项目有什么功能」「它能做什么」「有哪些能力」这类问题，
把 ctOS 2.0 的全部功能集中列一遍。

## 一句话概括

ctOS 2.0 是一个多模块的 AI 应用，把三种能力装在同一个网站里：
**闲聊对话**、**智能出行规划**、**智能客服问答**。
打开网页就能用，三个模块在页面顶部一键切换。

## 功能一：闲聊对话

页面上叫「闲聊」。点开就能像正常聊天一样说话。

具体能做这些事：

- **普通对话**：问什么答什么，回答会一个字一个字地实时显示出来（打字机效果），不用等整段生成完。
- **多轮对话**：会记住当前会话里最近的 10 条消息，可以说「再详细点」「换成 Python 写」这种接着上一句的话。
- **会话管理**：所有历史对话都存下来了，左侧栏能看到，可以随时点开任意一个接着聊，也可以删除。
- **会话自动命名**：用你说的第一句话的前 14 个字当会话标题。
- **停止生成**：回答太长跑太久，可以点停止按钮掐断。
- **记忆位置**：刷新页面后会回到上次停留的那个会话。

它背后是一张 LangGraph 对话图，接的是 DeepSeek 大模型。

适合用它来做：通用问答、写代码、解释概念、整理待办、随便聊。

## 功能二：智能出行（旅行规划）

页面上叫「智能出行」。用一句大白话说想去哪玩，它会自动帮你做完整套规划。

**一句话就能规划**，比如「下周想去杭州玩3天，带老人」，然后自动完成四步：

1. **查天气**——先认出你要去哪个城市、玩几天、什么时候出发，然后去查这几天真实的气温、下雨情况，并给出行建议。
2. **推荐景点**——结合天气和同行人推荐景点。下雨天不会给你推爬山，带老人会优先选好走的地方。需要时会联网搜门票价格、开放时间、要不要预约。
3. **安排行程**——把选出的景点分配到每一天，控制每天别太赶，同一天尽量安排位置相近的地方。
4. **规划路线**——把每天细化到具体时刻，算出每一段路的距离和耗时（打车还是走路），排成带时间点的完整路线。

**每一步的结果都会实时显示在页面上**，不是等全部跑完才出现。四步分别对应四张卡片。

其它功能：

- **多轮调整**：说「换成5天」「改成成都吧」「不要爬山了」，它会听懂这是对上一个需求的修改。
- **闲聊区分**：如果你只是打招呼说「你好」，它不会去跑整套规划，而是直接回一句话，省钱也省时间。
- **出行记录**：每次规划完都存下来了，左侧栏能看到出行记录，点开能恢复当时的四段结果，也能删除。
- **显示耗时**：规划要跑一两分钟，界面上会显示「规划中 12s」这样的计时，让你知道它还在动。
- **查实时数据**：天气来自 Open-Meteo 的真实预报；景点信息来自 Tavily 联网搜索；路线来自高德地图。

适合用它来做：做旅游攻略、安排几天行程、估算路上要多久、看目的地天气。

## 功能三：智能客服（查文档问答）

页面上叫「智能客服」。专门用来回答**关于 ctOS 这个项目本身**的问题。

能回答的问题类型举例：

- 「这个项目有哪些模块」「有什么功能」
- 「端口怎么改」
- 「数据库有几张表」
- 「为什么它不闲聊」
- 「报错说缺少 ZHIPU_API_KEY 怎么办」

它的工作方式是 RAG（检索增强生成）：先去知识库里找相关资料，再让大模型基于资料回答。
所以**回答有据可查，不会瞎编**。知识库里没有的内容，它会直接说「抱歉，我在知识库里没有找到相关答案。」

特点：

- **只查资料，不闲聊**——问它「今天心情不好」，它不会陪你聊。
- **不胡编**——资料里没有的，宁可说没找到，也不猜。
- **一问一答**——不记上下文，每次提问都是独立的一次检索。

三个模块共用一个网页、一个端口，顶部按钮切换，互不影响。
切换的时候，之前那个模块正在跑的任务不会被中断。
