# 06 我的数据

## 访客和注册账号，数据存哪不一样

| | 访客 | 注册账号 |
| --- | --- | --- |
| 聊天记录 | **存在你的浏览器里** | 存在服务器上 |
| 角色扮演记录 | 同上 | 同上 |
| 出行记录 | 同上 | 同上 |
| 换浏览器 / 清缓存 | **记录没了** | 记录还在 |
| 换设备 | 看不到 | 登录同一个账号就能看到 |

**建议**：随便试试用访客；想留住记录就注册。

## 各模块的记录情况

| 模块 | 记不记录 |
| --- | --- |
| 闲聊 | ✅ 存 |
| 角色扮演 | ✅ 存（含角色记忆） |
| 智能出行 | ✅ 存（路线、攻略、问答都存） |
| **智能客服** | ❌ **不存，刷新就没** |

## 数据安全吗

**账号之间互相隔离**：每个账号只能看到自己的数据，别人看不到你的聊天记录。

访客空间也是独立的，不同浏览器的访客空间互相看不见。

## 怎么删记录 / 怎么清除聊天记录

**删单个会话**：左侧栏里，会话右侧有删除按钮，点了就删。

**批量删**：左侧栏支持多选，选好几条一起删。

**删角色记忆**：角色聊天顶部 → 记忆面板 → 清空。

**删全部记录**：目前页面上没有「一键清空」，只能逐条删或批量删。想彻底清空，可以清浏览器缓存（访客身份）或者通过反馈联系管理员（注册账号）。

**删整个账号**：页面上没有提供，需要通过页面底部的「反馈」联系管理员。

（同义说法：删除聊天记录、清除对话历史、清空记录、删掉对话、擦除数据）

## 会不会被用来训练

不会。你的对话不会被拿去训练模型。

## 换设备怎么找回记录

**注册账号 + 登录同一个账号**即可。

如果是访客身份，换设备就找不回来了——访客空间只绑定当前浏览器。

## 清浏览器缓存会怎样

- **访客**：所有记录丢失（因为存在浏览器里）
- **注册账号**：记录在服务器上，不受影响，重新登录就看到了

## 数据存在哪个国家 / 谁的服务器

部署在这台服务器上（个人项目，自建）。
