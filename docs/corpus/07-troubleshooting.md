# 07 出问题了

## 页面打不开 / 一直转圈

**先刷新一次**（Ctrl+F5）。如果还不行：

1. **可能服务正忙**，等 30 秒再试
2. **换个浏览器试试**，排除是浏览器问题
3. **检查网络**，换个网络环境试试

如果一直打不开，可能是服务本身在重启，过几分钟再来。

## 发消息后没反应

- **看右上角有没有提示**：如果有错误提示，按提示操作
- **可能是回答太长还在生成**：看右下角有没有「规划中 xx s」的计时
- **点停止按钮重新发一次**

## 智能客服说「没找到相关资料」

**这是正常行为，不是坏了。** 它只根据知识库回答，查不到就说查不到，不会编。

试试：

1. **换个说法**（「怎么注册」→「我要开账号」）
2. **问具体一点**（「安全吗」→「我的聊天记录别人能看到吗」）
3. **确认你问的是这个网站的事**——问天气、写代码这类，该去「智能出行」或「闲聊」

## 生图一直不出来 / 报错

生图比较特殊：

- **比较慢**：一次要十几秒，属于正常
- **容易受影响**：画图服务有时候会超时

**试试**：重新发一次，或者换个简单的描述。

如果一直失败，可能是画图服务暂时不可用。

## 出行查不到路线

可能原因：

| 情况 | 怎么办 |
| --- | --- |
| 地名太笼统（「家」「学校」） | 说具体点：「杭州东站」而不是「车站」 |
| 地名写错了 | 检查一下拼写 |
| 城市对不上 | 加上城市名：「杭州的灵隐寺」 |
| 查的地点不在目标城市 | 换个准确的名字 |

## 攻略的天气不准

天气来自真实预报服务，但**越远越不准**：

| 天数 | 准确度 |
| --- | --- |
| 3 天内 | 比较准 |
| 7 天内 | 可参考 |
| 10 天内 | 仅供参考 |
| 超过 10 天 | 查不到，会告诉你 |

## 登录后记录还在，但换设备看不到

检查两件事：

1. **是不是用同一个账号登录的**
2. **原来那次是不是访客身份** —— 访客记录只存在当时的浏览器里，换设备找不回来

## 页面显示不全 / 样式乱了

按 **Ctrl+F5** 强制刷新（普通刷新可能用的是缓存）。

如果还不行，清除浏览器缓存再试。

## 还是解决不了

页面底部有「反馈」按钮，把你的问题和当时的情况写进去。我们会看到。
