# 03 角色扮演

## 是什么

和闲聊是同一个聊天界面，但是**换成一个设定好的人物在跟你说话**。

入口在**左侧栏的「角色扮演」**菜单，不在顶部三个标签里。

## 怎么开始玩

**三种方式**：

1. **用预设角色** —— 角色卡片点一下就能开聊（这些角色的性格、说话方式、背景都是提前设定好的）
2. **自己写一个** —— 填昵称、年龄、性别、性格、事迹、背景，不填完整也能用
3. **AI 帮我查** —— 输入一个角色名或描述，系统先联网找资料，再整理成一份角色档案草稿给你看，你确认后才保存

## 自己写角色时那些字段

所有字段**都可以空着**，空着就让 AI 自己补。

| 字段 | 填什么 |
| --- | --- |
| 昵称 | 这个角色叫什么 |
| 年龄 / 性别 | 随便填，影响不大 |
| 性格 | 比如「嘴硬心软」「说话很简洁」 |
| 人物事迹 / 背景故事 | 这个角色经历过什么 |
| 补充说明 | 特殊要求，比如「开场白：xxx」 |

**开场白**：在补充说明里写「开场白：你想让角色说的第一句话」，不写的话 AI 会根据人设自动生成一句。

## 角色记忆是什么

**每聊满 6 轮**，系统会自动把这 6 轮对话压缩成 200 字以内的摘要存起来。

下次和**同一个角色**再聊，它还记着之前聊过什么。

| 特点 | 说明 |
| --- | --- |
| 记忆跟着**角色**走，不跟着会话走 | 和同一个角色开过三次新对话，它仍然记得你 |
| 能查看 | 聊天顶部能看到「记忆」面板 |
| 能清空 | 记忆面板里可以清掉 |

## 几个常见问题

**问：角色会不会突然说自己是 AI？**

不会。所有角色都套了同一条规则：不跳出角色、不承认自己是 AI、不知道的事不编。

**问：一个会话能换角色吗？**

不能。一个会话只能绑定一个角色，想换角色要开新会话。

**问：自定义的角色保存在哪？**

存在服务器上，跟着你的账号走。

**问：角色扮演的记录和普通闲聊分开吗？**

分开列在左侧栏，但都存在同一个账号下。
