# 08 关于这个网站

## 用了什么 AI

| 用在哪 | 模型 |
| --- | --- |
| 闲聊对话 | DeepSeek |
| 角色扮演 | DeepSeek |
| 智能出行的路线和攻略 | DeepSeek |
| 智能客服的问答 | DeepSeek |
| **画图** | Seedream（豆包） |
| 智能客服的检索 | 本机的向量模型（qwen3-embedding） |

**一句话**：对话和推理用的是 **DeepSeek**，画图用的是 **Seedream**。

## 会不会有幻觉

**智能客服不会**——它只根据知识库回答，查不到就说没找到。

**闲聊、角色扮演、出行会**——大模型本身的特点，可能会编造细节。重要信息请自己核实。

## 免费吗 / 要钱吗 / 怎么收费

**完全免费。** 不要钱、不收费、不用绑银行卡、不用充值、没有会员、没有付费套餐、没有次数限制。

打开网站直接就能用，任何地方都不需要付钱。

## 有什么限制

目前的限制：

| 项 | 限制 |
| --- | --- |
| 聊天频率 | 没有硬性限制，但别连续刷 |
| 生图 | 一次十几秒，比较慢 |
| 单条消息长度 | 有上限，太长会提示 |
| 一次发几张图 | 有上限 |
| 天气 | 只能查 10 天以内 |

## 响应速度

| 操作 | 大概多久 |
| --- | --- |
| 闲聊一句话 | 几秒 |
| 智能客服回答 | 几秒 |
| 出行查路线 | 20~40 秒（要查真实地图数据） |
| 出行做攻略 | 40~90 秒（要查天气、搜景点、排行程） |
| 画一张图 | 10~20 秒 |

**页面右下角会显示实际花了多少秒。**

## 数据存在哪

服务器上的数据库里。访客的数据存在浏览器里。

详见「06 我的数据」。

## 是谁做的 / 能用来干什么

这是一个个人项目，用来展示 AI 应用开发能力。

**可以随便试用**，但不要用于商业用途。

## 技术上用了什么（一句话版）

Python 后端 + 网页前端，接 DeepSeek 大模型，用数据库存记录。

**更细的技术细节不属于用户关心的范围**，如果你想了解开发层面的东西，可以直接联系作者。
