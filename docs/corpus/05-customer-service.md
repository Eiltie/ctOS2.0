# 05 智能客服

## 是什么

顶部第三个标签。**专门回答关于 ctOS 这个网站本身的问题。**

注意：它是「问这个网站」的工具，不是陪你聊天的。想闲聊请用左边的「闲聊」。

## 能问什么

关于这个网站的一切：

- 有哪些功能、怎么用
- 访客和注册有什么区别
- 数据存在哪、会不会丢、怎么删
- 要不要钱、有什么限制
- 用了什么 AI 模型
- 报错了怎么办

## 不能问什么

跟这个网站无关的问题，它**不会回答**，会告诉你应该去哪个模块问：

| 你想问 | 该去哪 |
| --- | --- |
| 今天天气怎么样 | 智能出行 |
| 帮我写段代码 | 闲聊 |
| 讲个笑话 | 闲聊 |
| 路线怎么规划 | 智能出行 |

## 为什么它有时候说「没找到」

因为它**只根据资料回答，资料里没有就直说没找到，绝不编造**。

如果它说没找到，可以试试：

1. **换个说法再问一次**（比如「怎么注册」换成「我要开个账号」）
2. **问得更具体**（「数据安全吗」比「安全吗」更好）
3. **如果确实问的是这个网站的事，但一直答不上** —— 那可能是知识库还没覆盖到，可以通过页面底部的「反馈」告诉我们

## 它和闲聊的区别

| | 闲聊 | 智能客服 |
| --- | --- | --- |
| 什么都能聊 | ✅ 是 | ❌ 只答网站相关 |
| 会不会编 | ⚠️ 可能会 | ✅ 不会，只根据资料 |
| 能追问 | ✅ 能 | ✅ 能（能接上一句的「它」指什么） |
| 记录存不存 | 存 | **不存**，刷新就没了 |

## 常见问题

**问：为什么它不跟我闲聊？**

因为它只有「查资料回答问题」这一个职责，闲聊这件事已经由「闲聊」模块承担了。

不过你问「你好」「谢谢」「在吗」这类寒暄，它会回一句引导语，告诉你可以问什么。

**问：问答记录会保存吗？**

不会。问答不写数据库，**刷新页面就没了**。想留着请自己复制。

**问：它能记住我刚才问的吗？**

同一个页面里能记住最近几轮，所以可以问「那它怎么配置」这种带「它」的追问。但刷新后就忘了。

**问：它是不是什么都查资料？**

是的。每个问题都会先去知识库检索，再基于检索到的内容回答。所以**回答有出处，不会瞎编**。
