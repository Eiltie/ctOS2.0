# 01 开始使用

## 打开网站会看到什么

打开 <https://ctos2.cn> 会直接进入，**不需要注册也能用**。

页面顶部有三个标签，点一下就切换：

```
闲聊      智能出行      智能客服
```

角色扮演不在这三个标签里，它在**左侧栏**的「角色扮演」菜单下面。

## 访客和注册账号的区别

首次打开时会自动创建一个**访客空间**。

| | 访客（不用注册） | 注册账号 |
| --- | --- | --- |
| 要不要填东西 | 不用，打开就能用 | 填邮箱和密码 |
| 聊天记录 | 只存在当前浏览器里 | 存服务器，换设备也能看到 |
| 换浏览器 / 清缓存 | **记录会没** | 记录还在 |
| 用手机再打开 | 看到的是一个新空间，之前的记录不在 | 登录同一个账号，记录都在 |

**结论**：

- **随便试试** → 用访客，什么都不用填
- **想留住记录** → 点右上角头像 → 「登录 / 注册」，用邮箱注册一个

## 怎么注册

1. 点右上角头像
2. 选「登录 / 注册」
3. 填邮箱和密码（密码至少 6 位）
4. 注册完自动登录

**注册后**：之前访客空间里的记录**不会转过来**，它属于那个访客空间。想保留的话，先把想要的内容复制出来。

## 手机上能用吗

能。手机浏览器打开同一个网址就行，界面会自动适配。

**但注意**：手机上如果是访客身份，记录存在手机浏览器里；在电脑上又想看，得注册账号登录。

## 免费吗 / 要钱吗 / 怎么收费

**完全免费，不要钱，不收费，不需要绑卡，不需要充值，没有会员，没有付费套餐。**

打开就能用，没有任何需要付钱的地方。

**要花钱吗** → 不要。**收费吗** → 不收费。**有免费额度吗** → 不限制，不用额度。
**要充值吗** → 不需要。**有会员吗** → 没有。

## 有使用次数限制吗

目前**没有做次数限制**，但有一点要注意：

- **生图**每次都会真实调用一次画图服务，比较慢（十几秒），请别连续刷
- 如果发现响应变慢或者报错，可能是这个时间段用的人多，过一会儿再试

## 页面上的东西都是什么意思

| 你看到的 | 意思 |
| --- | --- |
| 左上角头像 | 点开是登录 / 注册 / 退出 |
| 左侧栏 | 你的历史记录列表（谈话、出行记录） |
| 顶栏三个标签 | 切换模块 |
| 右下角「规划中 12s」 | 当前这次处理用了多少秒 |
| 停止按钮 | 回答还在生成时，可以点它掐断 |
