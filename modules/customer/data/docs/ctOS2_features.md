# ctOS 2.0 有哪些功能

本文专门回答「这个项目有什么功能」「它能做什么」「有哪些能力」这类问题，
把 ctOS 2.0 的全部功能集中列一遍。

## 一句话概括

ctOS 2.0 是一个多模块的 AI 应用，把四种能力装在同一个网站里：
**闲聊对话**、**角色扮演**、**智能出行规划**、**智能客服问答**。
打开网页就能用，三个页面标签一键切换，角色扮演在侧栏的「角色扮演」菜单里。

**线上地址：<https://ctos2.cn>**（`www.ctos2.cn` 同样可访问），
打开就先进一个访客空间；注册一个账号登录后，每个账号看到的历史记录是自己的，互不可见。
自己部署的话，本地访问 <http://127.0.0.1:8080/>，页面完全一样。

## 功能一：闲聊对话

页面上叫「闲聊」。点开就能像正常聊天一样说话。

具体能做这些事：

- **普通对话**：问什么答什么，回答会一个字一个字地实时显示出来（打字机效果），不用等整段生成完。
- **多轮对话**：会记住当前会话里最近的 10 条消息，可以说「再详细点」「换成 Python 写」这种接着上一句的话。
- **会话管理**：所有历史对话都存下来了，左侧栏能看到，可以随时点开任意一个接着聊，也可以删除。
- **会话自动命名**：用你说的第一句话的前 14 个字当会话标题。
- **停止生成**：回答太长跑太久，可以点停止按钮掐断。
- **记忆位置**：刷新页面后会回到上次停留的那个会话。

它背后是一张 LangGraph 对话图，接的是 DeepSeek 大模型。

适合用它来做：通用问答、写代码、解释概念、整理待办、随便聊。

## 功能二：角色扮演

在闲聊里换一种玩法的入口。左侧栏有一个可折叠的「角色扮演」菜单，角色对话和普通聊天分开列。

具体能做这些事：

- **预设角色**：点卡片就能开聊，角色档案（性格、说话方式、边界、开场白）是写死在代码里、手工调过的。
- **自己写角色**：填昵称、年龄、性别、性格、人物事迹、背景故事、补充说明，所有字段都可以空着。
  补充说明里写「开场白：xxx」就用你写的那句，没写就让 AI 根据人设生成一句。
- **AI 帮我查**：输入一个角色名或描述，先联网搜资料，再由模型整理成一份角色档案草稿。
  草稿会先给你看、可以改，确认后才存进数据库。
- **角色记忆**：每聊满 6 轮，后台自动把最近的对话压缩成 200 字以内的摘要。
  下次再和这个角色聊，它还记得上次聊过什么；也可以随时查看和清空记忆。
- **角色档案**：聊天顶部可以查看这个角色的完整设定。

几个特点：

- **角色之间互不串戏**：一个会话只能绑定一个角色，用错角色去开会直接报错。
- **记忆跟着角色走，不跟着会话走**：和同一个角色开过三次新对话，它仍然记得你。
- **不会承认自己是 AI**：所有自定义角色都套用同一条边界规则，不跳出角色、不编造不知道的事。

## 功能三：智能出行（路线决策 + 旅游攻略）

页面上叫「智能出行」。它有两种模式，会自己判断你这句话属于哪一种：
问「从 A 到 B 怎么走」就是**路线决策**，问「去某地玩几天」就是**旅游攻略**。

### 模式一：路线决策（伪导航）

用一句话说清起点和终点，比如「从杭州东站到灵隐寺怎么走，带老人，少走路」。

1. **确认需求**：认出起点、终点、出发时间、偏好（最快 / 最省钱 / 少走路 / 少换乘）、同行人。
   起点太笼统（只说「家」「学校」）或者地名查不到时，会先反问，不瞎猜。
2. **查真实候选**：用高德地图查驾车、公交地铁、步行、骑行，最多摆出 2~4 条。
   每条带距离、耗时、费用、步行距离、换乘次数、当前路况。
3. **暂停让你选**：查完不会直接下结论，而是停住，把候选方案摆出来让你选一条
   （系统会给一条推荐，但以你的选择为准）。
4. **写结论**：你选完之后，才写「候选对比」「推荐理由」「出发提醒」三段。

它不会画地图、不会语音播报，只做路线分析和决策。

### 模式二：旅游攻略（原流程 + 两个暂停点）

用一句大白话说想去哪玩，比如「下周想去杭州玩3天，带老人」。

1. **查天气**：认出城市、天数、出发日期，查真实气温和下雨情况，给出行建议。
2. **推荐景点**：结合天气和同行人推荐景点，需要时联网查门票、开放时间、要不要预约。
3. **暂停让你勾选**：景点清单出来后停住，你可以勾掉不想去的、再补一个想去的，确认后才继续。
4. **安排行程**：按你确认后的景点分配到每一天，控制每天别太赶。
5. **规划路线**：细化到具体时刻，算出每段路的距离和耗时，排成带时间点的完整路线。
6. **问要不要查真实路线**：攻略出完后会问一句，选了才用高德把每天相邻站点之间的真实距离和耗时再算一遍，
   结果作为第五段「真实路线」显示。

**每一步的结果都会实时显示在页面上**，不是等全部跑完才出现。

### 两种模式共同的

- **多轮调整**：说「换成5天」「改成成都吧」「那坐地铁呢」「改成8点出发」，它会听懂这是对上一个需求的修改。
- **闲聊区分**：如果你只是打招呼说「你好」，它不会去跑整套规划，而是直接回一句话。
- **出行记录**：每次跑完都存下来了，左侧栏能看到出行记录，点开能恢复当时的结果，也能删除。
  每条记录带一个 `turn_kind` 标记：`ROUTE` 表示路线决策，`TRAVEL` 表示旅游攻略，
  `CHAT` 表示这句话被判定为闲聊、只回了一句话。
- **显示耗时**：界面上会显示「规划中 12s」这样的计时。中途停下来等你选择时，计时会暂停，
  不会把你思考的时间算进去。
- **查实时数据**：天气来自 Open-Meteo 的真实预报；景点信息来自 DeepSeek Search 联网搜索；
  路线和地点来自高德地图。

适合用它来做：查从 A 到 B 怎么走最快、比较打车和公交哪个划算、做旅游攻略、安排几天行程、看目的地天气。

## 功能四：智能客服（查文档问答）

页面上叫「智能客服」。专门用来回答**关于 ctOS 这个项目本身**的问题。

能回答的问题类型举例：

- 「这个项目有哪些模块」「有什么功能」
- 「端口怎么改」
- 「数据库有几张表」
- 「为什么它不闲聊」
- 「报错说缺少 ZHIPU_API_KEY 怎么办」

它的工作方式是 RAG（检索增强生成）：先去知识库里找相关资料，再让大模型基于资料回答。
所以**回答有据可查，不会瞎编**。知识库里没有的内容，它会直接说「抱歉，我在知识库里没有找到相关答案。」

特点：

- **只查资料，不闲聊**——问它「今天心情不好」，它不会陪你聊。
- **不胡编**——资料里没有的，宁可说没找到，也不猜。
- **能接追问**——可以问完一个问题接着问「那它怎么配置」，它会结合上一句理解「它」指的是什么。
- **不存记录**——问答不写数据库，刷新页面就没了（闲聊、角色扮演和出行的记录会存）。

四个能力共用一个网页、一个端口，顶部按钮切换，互不影响。

## 常见问题：智能出行

**问：旅游攻略可以勾选景点吗？**

可以。景点清单出来后流程会暂停，你可以勾掉不想去的景点，也可以补一个想去的，
点「就这样，继续排行程」之后才会继续。

**问：路线决策会停下来让我选方案吗？**

会。查完候选路线后流程会停住，把几条方案摆出来让你选一条，选完才写对比、推荐和出发提醒。

**问：智能出行的计时会把我思考的时间算进去吗？**

不会。停在选择面板时计时会暂停，右下角显示「等待选择」，你选完才接着算。
切换的时候，之前那个模块正在跑的任务不会被中断。
